# DND — Asistente de combate

Asistente para dirigir combates de D&D 2024 con dados físicos: iniciativa, ataques, daño, hechizos,
concentración, salvaciones de muerte, inventario y botín. A la izquierda muestra la historia de la
aventura (con saltos a cada sección y efectos de sonido); a la derecha, el combate.

Abrir `index.html` en el navegador (no necesita instalar nada).
Guía de uso y cómo añadir personajes, enemigos u objetos: [INSTRUCCIONES.md](INSTRUCCIONES.md).
